# 자격증명 만료·회전·정리 소유권 (2026-11-08)

keycli는 **자동 갱신도, 전역 스윕도 하지 않는다.** 만료·회전·폐기의 소유자는 사람이다.
이 문서는 그 소유권과, 코드가 강제하는 경계를 고정한다.

## 1. 원칙

1. **자동 갱신 없음** — 만료된 시크릿은 조용히 갱신되지 않는다. 실패는 실패로 드러난다.
2. **전역 스윕 없음** — 저장소 전체를 돌며 오래된 값을 지우지 않는다.
3. **만료는 메타데이터** — `kc ls`의 `expires`는 표시일 뿐 강제가 아니다. 강제는 플랫폼 토큰의 만료가 한다.
4. **덮어쓰기는 명시적** — 번들 import가 기존 값을 조용히 교체하지 않는다.

## 2. 자격증명 등급과 기대 수명

| 등급 | 예 | 기대 수명 | 회전 소유자 | 탐지 |
| --- | --- | --- | --- | --- |
| 플랫폼 단발 토큰 | `dev_cf_worker_read` (24h) | ≤ 24h | 소유자 | `kc ls` `expires`, API `expires_on` |
| 발급용 토큰 | `cloudflare_agent` | 사람이 관리 | 소유자 | `kc ls` 메타데이터 |
| 서비스 토큰 | `dev_study_service_token` | 세대 결합 | 소유자 (그룹 단위) | 해시 대조 |
| 외부 제공자 키 | `sogang-pw`, `clerk_secret_key` | 제공자 정책 | 소유자 | 없음 |
| 파생 해시 | `dev_api_token_sha256` | 원본과 동일 세대 | 원본과 함께 | 해시 MATCH |

## 3. 코드가 강제하는 것 (2026-11-08 기준)

- **import 덮어쓰기 거부** — 기존 이름이 포함된 번들은 `--force` 없이는 실패한다.
  ```
  Error: refusing to overwrite 1 existing secret(s): kc_p4_existing (re-run with --force)
  ```
- **만료 없음 경고** — import 성공 시 `imported N secret(s) with no expiry — record rotation ownership`을 stderr에 남긴다.
- **guarded import**는 기존과 같이 `SetIfAbsent`로 덮어쓰지 않는다.

강제하지 않는 것: 만료 후 사용 차단, 자동 삭제, 회전 알림.

## 4. 일회성 토큰 정리 절차

P4-1에서 확인한 사실을 절차로 고정한다.

1. 발급 주체(`Account API Tokens Write`)로 일회성 토큰을 만든다.
2. 사용 후 **발급 주체로** 삭제한다. 일회성 토큰 스스로는 자기 삭제가 **403**이다.
3. 남은 토큰 목록을 확인한다: `GET /accounts/{id}/tokens`.
4. 로컬 사본(파일·env)이 있으면 삭제한다.

## 5. 재발급 예시 (24h 읽기 토큰)

`dev_cf_worker_read`는 24시간마다 재발급한다. 절차: 발급 → `kc set`으로 교체 → 5개 Worker GET 200 확인 →
**이전 토큰 삭제**. 2026-11-08 실행에서 이 순서로 교체했고, 남은 계정 토큰이 1건임을 확인했다.
